# Runtime dependencies for the training job. Installed by BOTH the Docker
# image and the local .venv, which is what keeps "it worked in my notebook"
# and "it worked in the container" the same claim.
#
# Every version is pinned exactly so a rebuild in six months produces the same
# numbers. Adding a dependency means adding a line here with an explicit
# version and rebuilding the image.
#
# NOTE: keep this file UTF-8 with LF endings. PowerShell's `pip freeze >
# requirements.txt` writes UTF-16, which pip inside the Linux container cannot
# parse. Use `pip freeze | Out-File -Encoding utf8 requirements.txt` instead.
